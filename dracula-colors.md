# Paleta Dracula

Referência de cores do tema Dracula para a personalização do Arch (editor, terminal, WM/DE, apps).
Fonte: paleta oficial em https://draculatheme.com/contribute

## Cores principais

| Nome | Hex | Uso comum |
|---|---|---|
| Background | `#282a36` | Fundo de janelas, editor e terminal |
| Current Line / Selection | `#44475a` | Linha atual, seleção, bordas inativas |
| Foreground | `#f8f8f2` | Texto principal |
| Comment | `#6272a4` | Comentários, texto secundário |
| Cyan | `#8be9fd` | Tipos, links, destaques |
| Green | `#50fa7b` | Strings, sucesso, funções |
| Orange | `#ffb86c` | Parâmetros, avisos suaves |
| Pink | `#ff79c6` | Keywords, borda da janela ativa |
| Purple | `#bd93f9` | Constantes, acento principal |
| Red | `#ff5555` | Erros, alertas |
| Yellow | `#f1fa8c` | Strings, avisos |

## Extra

| Nome | Hex | Uso comum |
|---|---|---|
| Background escuro | `#21222c` | Barras laterais, painéis, "preto" ANSI |

## Formatos úteis

- Hyprland (`rgba`): `rgba(bd93f9ff)`, `rgba(ff79c6ff)`, `rgba(44475aaa)`
- CSS: `--bg: #282a36; --fg: #f8f8f2; --purple: #bd93f9; --pink: #ff79c6;`
